# Local AI Lab – online demo

Local AI Lab is an offline-first workbench that runs on your own computer: chat with local models, ask questions
about your documents with page citations, benchmark models with confidence intervals, compare machine-learning
models fairly on your own data (Model Arena), test AI agents for correct and safe tool use (Agent Arena), and let a
local Work Agent handle files with your approval.

**This online demo uses the built-in model simulator**, so answers and timings are examples, not real model
measurements. The real application runs local models with [Ollama](https://ollama.com) on your own computer, and
your data never leaves it.

* Source code and installation: <https://github.com/Khizer45/LocalAILab>
* This is a shared public space that is reset every few hours. **Do not upload private or personal files.**
* Administration, settings, backups, model downloads and the OpenAI-compatible API are disabled here.
