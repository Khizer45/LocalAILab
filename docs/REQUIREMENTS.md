### Model Arena and Agent Arena (v1.1)

Added after the first release so that anyone who installs the system can compare **their own datasets and models** and evaluate **local models as agents**.

| ID | Requirement | Implementation | Verified by |
|---|---|---|---|
| FR-13 | User can upload their own dataset (CSV tabular/text, ZIP of images) and get a reproducible train/test split with a data-quality profile | `arena/data.py`, `arena/service.py`, `POST /api/arena/datasets(/preview)`, Model arena → Datasets | `test_csv_preview_suggests_target_and_types`, `test_tabular_dataset_profile_and_stratified_split`, `test_regression_and_text_detection`, `test_bad_csv_inputs_are_rejected`, `test_image_zip_layouts_and_zip_slip` |
| FR-14 | User can upload their own trained models (ONNX, scikit-learn joblib) incl. image CNNs such as MobileNetV2/EfficientNet, with preprocessing and label mapping | `arena/uploaded.py`, `arena/images.py`, `POST /api/arena/models` | `test_image_comparison_with_onnx_classifier_and_feature_extractor`, `test_tabular_comparison_with_uploaded_joblib_model`, `test_wrong_output_size_and_unsupported_formats`, `test_feature_tensor_detection` |
| FR-15 | System trains and compares built-in algorithms, uploaded models and local LLMs on the same held-out test split (classification and regression; transfer learning for images) | `arena/algorithms.py`, `arena/runner.py`, `POST /api/arena/runs` | `test_every_available_algorithm_trains_on_every_kind`, `test_regression_comparison_with_tuning`, `test_text_comparison_with_local_llm`, `test_llm_only_for_text_classification` |

### Evaluation protocol, recovery, security and automation (v1.2)

Added in v1.2: results must be honest, installations must be
recoverable, and the app must be usable from other tools without weakening privacy.

| ID | Requirement | Implementation | Verified by |
|---|---|---|---|

## Non-functional requirements

| Area | Requirement | How it is met | Evidence |
|---|---|---|---|
| Privacy | In offline mode prompts, documents and embeddings are not sent to external providers | Two-layer network guard; local-only embedders; documents-to-cloud policy; fonts bundled; telemetry opt-outs | `test_full_workflow_makes_only_loopback_connections` records every socket connection during chat, RAG, benchmark and ML training with MLflow: all loopback |
| Security | Auth where needed, access control, input validation, secure file handling, secrets protection | Optional token auth with scoped API tokens, rate limiting, remote-access and DNS-rebinding guards, audit log, sandboxed uploaded models, owner checks (404 for foreign objects), Pydantic validation, upload signature/size checks, UUID file names + `safe_join`, hashed passwords/tokens, key only in backend env, CSP, no images from model output; Model Arena: zip-slip/zip-bomb checks, ONNX instead of pickle, pickles admin-only + explicit trust, SHA-256-verified downloads blocked offline; Agent Arena: mocked risky tools, AST-whitelisted calculator | `test_auth.py`, `test_path_traversal_is_rejected`, `test_uploaded_filename_cannot_escape_storage`, `test_api_key_never_exposed`, `test_password_hashing`, `test_security_headers`, `test_image_zip_layouts_and_zip_slip`, `test_arena_isolation_and_admin_only_pickles`, `test_backbone_download_blocked_offline`, `test_calculator_is_safe`, `test_cloud_models_blocked_and_runs_isolated` |
| Reliability | Useful error when a model is unavailable; API does not hang | Error mapping with hints; connect/read timeouts; overall generation deadline; failed runs marked; interrupted runs recovered at start | `test_runtime_down_returns_503`, `test_unknown_model_gives_readable_error`, `test_generation_deadline_raises_timeout` |
| Performance | Latency, throughput and memory are measured; no fixed guarantee | Metrics with provenance labels; single benchmark worker to avoid interference; warm-up option | `test_quick_suite_two_models` |
| Maintainability | Modular code, env configuration, documentation | Layered packages (api/core/services/benchmark/ml), `Settings`, ruff, manuals | `ruff check` in CI |
| Testability | Unit, API integration, privacy-mode, benchmark, statistics and browser tests | 249 backend tests using a real HTTP simulator (with tool calling), statistical simulations, Vitest component tests, Playwright end-to-end tests; smoke test covering all features | `pytest` (all pass on Python 3.11 and 3.13), `npm test`, `npx playwright test` |
| Portability | Windows development and Docker-compatible deployment | `.bat` scripts, pathlib everywhere, CRLF scripts, Docker Compose variants | scripts reviewed; compose validated |
| Usability | Clear dashboard, model status, progress indicators, readable errors | data-boundary strip, health checks, live progress bars, errors with hints | screenshots in `docs/images` |
| Statistical validity (Model Arena) | Comparisons are fair, the reported score is unbiased and uncertainty is shown | train/validation/test with selection on validation only, group/time splits, cluster/stratified bootstrap, TOST equivalence + Holm, leakage checks, baseline always included; simulation-validated coverage and error rates | `tests/test_arena_protocol.py`, `scripts/validate_statistics.py` |
| Reproducibility | Model name/version, parameters, dataset version and config saved | run stores suite snapshot + cases SHA-256, evaluator versions, config, seed, order, model digest/size/quantization, Ollama version, hardware; split SHA-256; verifiable experiment bundles | `test_runs_are_reproducible`, `test_all_suites_are_valid_and_versioned`, `test_suite_is_frozen_when_the_run_is_submitted`, `test_exported_predictions_reproduce_reported_metrics`, `test_benchmark_bundle_round_trip_and_metadata_scope` |
| Recoverability (v1.2) | Upgrades and mistakes do not lose data | Alembic migrations with a pre-migration copy, verified backups, staged restore that keeps the replaced data | `tests/test_migrations_backup.py` |
| Legal (v1.2) | Shipped software and recommended models can be used legally | AGPL PyMuPDF replaced by pypdf, licence report in CI, model licences and commercial-use flags in the catalogue, research-only model removed from recommendations | `scripts/license_report.py`, `test_catalog_has_licences_and_flags_research_only_models`, `docs/LEGAL_AND_LICENSING.md` |
